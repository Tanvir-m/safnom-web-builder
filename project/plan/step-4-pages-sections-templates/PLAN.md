# Step 4 — Plan

## Goal

Flexible content model for websites without a visual editor.

## Scope

- Page CRUD nested under workspace websites
- Embedded sections (single collection, flexible `data` / `settings`)
- Section add / update / delete / duplicate / reorder
- Template catalog + apply on website create
- Website `theme` and `settings` fields

## Out of scope

Visual editor, preview, publishing, media, AI.
